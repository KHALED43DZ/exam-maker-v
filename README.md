# مولّد أوراق الامتحان — الإصدار 1.6.0

تطبيق ويب من صفحة واحدة لإنشاء أوراق الامتحان بترويسة وزارة التربية الوطنية الجزائرية، مع أنواع أسئلة متعددة وطباعة A4 ونموذج إجابة. يعمل بالعربية (RTL) على الحاسوب والهاتف دون تثبيت.

## محتويات الحزمة
- `index.html` — التطبيق كاملاً (يتضمن البيانات).
- `manifest.webmanifest` — بيان التطبيق (الاسم والأيقونات) للتثبيت.
- `sw.js` — عامل الخدمة للعمل دون إنترنت.
- `icons/` — أيقونات التطبيق.
- `README.md` — هذا الملف.
- `CHANGELOG.md` — سجل الإصدارات.
- `.nojekyll` — ملف فارغ يمنع معالجة GitHub Pages للموقع (ارفعه مع بقية الملفات؛ قد يكون مخفياً في مدير الملفات).

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على github.com (مثلاً `exam-maker`) واجعله **Public**.
2. اضغط **Add file ← Upload files**، وارفع محتويات هذه الحزمة بعد فك الضغط (وليس ملف zip نفسه)، ثم **Commit changes**.
3. من **Settings ← Pages**: اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
4. بعد دقائق يظهر الرابط: `https://اسم-المستخدم.github.io/exam-maker/`

## التثبيت كتطبيق (PWA)
بعد النشر على GitHub Pages (رابط https) افتح الرابط:
- **أندرويد / Chrome وحاسوب:** اضغط زر «📲 تثبيت التطبيق» أعلى الصفحة، أو من قائمة المتصفح اختر «تثبيت التطبيق».
- **آيفون / Safari:** اضغط «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».

بعد أول زيارة يعمل التطبيق دون إنترنت (الخطوط الإضافية تحتاج اتصالاً في أول مرة). لا يعمل التثبيت عند فتح الملف مباشرة من الجهاز، بل يلزم رابط https.

**عند نشر إصدار جديد:** غيّر اسم الإصدار `V` في أول سطر من `sw.js` ليحدّث المتصفح الملفات المخزّنة.

## الاستخدام المحلي
افتح `index.html` في متصفح Chrome مباشرة.

## ملاحظات
- تُحفظ الورقة تلقائياً في متصفح الجهاز (localStorage)، فلا تنتقل بين الأجهزة.
- الإملاء الصوتي يحتاج Chrome وإذن الميكروفون واتصالاً بالإنترنت.
- الخطوط (أميري، القاهرة، تجوال، نسخ) تُحمَّل من Google Fonts، فتحتاج اتصالاً بالإنترنت وإلا استُخدمت خطوط النظام.
- للطباعة: اختر حجم A4، وفعّل «الرسومات الخلفية»، وأوقف الرأس والتذييل. هوامش الطباعة قابلة للضبط من «التنسيق» (للهاتف وللحاسوب). بعض الطابعات وخدمات الطباعة تفرض هوامش دنيا أكبر؛ للحصول على هامش دقيق احفظ الورقة PDF ثم اطبعها.
- خط مجمع الملك فهد لرواية ورش غير مضمَّن؛ يُعرض النص بخط «أميري القرآني» الاحتياطي، وقد تختلف بعض علامات ورش.
- راجع نصوص القرآن والأحاديث قبل اعتمادها في الامتحانات.
